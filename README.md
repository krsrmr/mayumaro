# 마유마로 선생님

유니챗 캐릭터 '마유마로 선생님'의 작품 소개 페이지입니다.
가상의 여성향 웹코믹 스토어 작품 상세, 작가 프로필(센뵤 페인트), '당신' 크로키북 페이지로 구성됩니다.

- 페이지: `index.html`
- 이미지: `img/` 폴더 (규격은 [img/README.md](img/README.md))

## v2: 일체형 스크롤판 (초안)

- 페이지: `v2/index.html` (주소 끝에 `/v2/`)
- 세 화면을 나누지 않고 한 번에 스크롤해서 읽는 구성입니다: 표지 → 화제(독자 댓글·휴재) → 작가 인터뷰 → 줄거리·학교·회차 → 캐릭터(작업용 모니터 속 센뵤 페인트, 전신 + 옆 정보) → 당신(크로키북 한 장) → 연재 장르 → 플레이 안내
- 유니챗 소개글의 인터뷰, 플레이 기본, 유저노트 양식(복사 버튼), 내장 위젯, 추천 모델까지 합쳤습니다.
- 이미지는 같은 `img/` 폴더를 씁니다. `img/main.webp`(소개글 메인 그림)를 넣으면 휴재 안내 아래에 뜨고, 없으면 그 자리가 숨겨집니다.
- 작업본: `v2/draft.html` (주소 끝에 `/v2/draft.html`). 인트로 3종 '시작점' 블록과 '무대는 오사카' 안내를 더한 판입니다. 그림 `img/intro-*.webp`가 들어오면 `v2/index.html`에 그대로 덮어씁니다.
- 작업본에는 왼쪽 아래 '컨셉 BGM' 플레이리스트(5곡, 유튜브)도 들어 있습니다. 곡을 누를 때만 재생되고, 곡 목록은 `draft.html` 아래쪽 `const TRACKS`에서 바꿉니다.
