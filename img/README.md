# 이미지 가이드

이 폴더에 아래 **파일 이름 그대로** webp 이미지를 넣으면 사이트의 회색 플레이스홀더 자리에 자동으로 표시됩니다.
파일이 없으면 플레이스홀더가 그대로 남으니, 준비된 것부터 하나씩 넣어도 괜찮습니다.

## 참고
- 이미지는 칸에 꽉 차게 잘려서 들어갑니다(가운데 기준). 비율을 맞추면 잘리는 부분이 없습니다.
- 표지 2종(`cover-*`)은 작품 제목이 정해지면 그 제목에 맞춰 만들면 됩니다.
- 파일 이름은 영어 소문자와 하이픈만 씁니다. 이름이 한 글자라도 다르면 표시되지 않습니다.
- 다른 이름을 쓰고 싶으면 `index.html` 아래쪽 `const IMAGES = { ... }` 부분의 경로를 바꾸면 됩니다.
