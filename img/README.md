# 이미지 가이드

이 폴더에 아래 **파일 이름 그대로** webp 이미지를 넣으면 사이트의 회색 플레이스홀더 자리에 자동으로 표시됩니다.
파일이 없으면 플레이스홀더가 그대로 남으니, 준비된 것부터 하나씩 넣어도 괜찮습니다.

| 파일 이름 | 비율 | 권장 크기 | 들어가는 곳 | 내용 |
|---|---|---|---|---|
| `key-visual.webp` | 7:10 | 1400×2000 | 스토어 작품 상세 표지, PC 상단 큰 표지 (회차 표지가 없을 때 회차 썸네일 대신) | 마시로 키비주얼. 작품 표지 느낌. **제목 글자는 넣지 않기** (페이지가 따로 표시) |
| `fullbody.webp` | 1:2 또는 9:16 | 1000×2000 또는 1080×1920 | 등장인물 소개 썸네일, 센뵤 페인트(프로필 페이지) 캔버스 | 마시로 전신. 서 있는 자세, 배경은 단순하게. 9:16이면 좌우가 약 5%씩 잘리니 인물은 가운데에. 썸네일은 위쪽(얼굴) 기준으로 잘림 |
| `avatar.webp` | 1:1 | 512×512 | 작가 계정(@mayumaro_works) 프로필 사진 | 마시멜로 일러스트. 귀엽고 여성 작가처럼 보이는 아이콘 |
| `cover-bl.webp` | 7:10 | 700×1000 | 작가의 다른 작품 목록 | BL 화제작 표지 |
| `cover-tl.webp` | 7:10 | 700×1000 | 작가의 다른 작품 목록 | TL 화제작 표지 |
| `cover-adult.webp` | 7:10 | 700×1000 | 작가의 다른 작품 목록 | 상업지 화제작 표지 |
| `ep1.webp` ~ `ep5.webp` | 7:10 | 700×1000 | 회차 목록 1~5화 썸네일 | 회차별 표지. 마시로(모브 얼굴) + 유저(하얀 마네킹). 파일이 없으면 키비주얼이 대신 뜸 |

## 참고
- 이미지는 칸에 꽉 차게 잘려서 들어갑니다(가운데 기준). 비율을 맞추면 잘리는 부분이 없습니다.
- 표지 3종(`cover-*`)은 작품 제목이 정해지면 그 제목에 맞춰 만들면 됩니다.
- 파일 이름은 영어 소문자와 하이픈만 씁니다. 이름이 한 글자라도 다르면 표시되지 않습니다.
- 다른 이름을 쓰고 싶으면 `index.html` 아래쪽 `const IMAGES = { ... }` 부분의 경로를 바꾸면 됩니다.
